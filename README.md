# SQUADBOARD

미드나잇FC(파주/고양 실내풋살) 매치 매니저입니다. 단일 HTML 파일(`index.html`)로 동작하며, 별도 서버나 빌드 과정 없이 브라우저에서 바로 열립니다.

## 포함 기능

- 회원 능력치 아카이빙 (6개 카테고리, 레이더 차트)
- 참석 인원 기반 팀 밸런싱 (2파전/3파전, 스네이크 드래프트)
- 매치데이 쿼터 타이머 + 키퍼 로테이션 알림 (개인 화면 / 공용 화면 모드)
- **Firebase Firestore 기반 실시간 공유 저장** — 어떤 기기로 접속하든 항상 같은 최신 데이터를 봄

## GitHub Pages로 배포하는 방법

1. 이 저장소에 `index.html`을 그대로 올립니다 (기존 파일이 있다면 덮어쓰기/커밋).
2. GitHub 저장소의 **Settings → Pages**에서 배포 브랜치를 선택하면, `https://<계정명>.github.io/<저장소명>/` 주소로 열립니다. 이 주소가 앞으로 동호회원들과 공유할 고정 링크입니다.

## 데이터 저장 방식

이 파일은 Firebase Firestore(무료 클라우드 데이터베이스)에 실시간으로 연결되어 있습니다. 즉 PC든 휴대폰이든, 이 링크를 여는 모든 기기가 항상 같은 실데이터를 실시간으로 보고 씁니다 — Claude 아티팩트에서 겪었던 "버전 고정/동기화 지연" 문제 자체가 없는 구조입니다.

Firebase 프로젝트(`squad-board-8d46e`)의 Firestore 보안 규칙은 로그인 없이 누구나 읽고 쓸 수 있도록(`allow read, write: if true`) 설정되어 있습니다 — 기존 "링크 아는 사람 누구나 수정 가능" 모델과 보안 수준이 동일합니다. 더 엄격한 접근 제어(운영진만 쓰기 가능 등)가 필요해지면 알려주세요, Firebase Authentication 연동을 도와드릴 수 있습니다.
